如何啟動本機代理？

在終端機設定環境變數後啟動：

export BYSE_API_KEY='你的 API Key'
uv run --no-project python byse_full_suite/server.py

請先依 README 安裝依賴。接著開啟 http://127.0.0.1:5000，即可使用代理連線。
